원장톡 설치하기

내려받고, 실행하고, 인증코드를 넣으면 끝이에요. 처음 한 번만 하면 돼요.

  1. 1내려받기
  2. 2실행하기
  3. 3인증코드 넣기

설치 중에 경고가 떠도 괜찮아요

원장톡을 처음 받으면 브라우저와 윈도우가 「일반적으로 다운로드되지 않습니다」, 「Windows의 PC 보호」 같은 경고를 띄울 수 있어요.

  • 바이러스가 발견됐다는 뜻이 아니에요. 아직 많은 사람이 받지 않은 새 프로그램이면, 한 번 더 확인하라고 띄우는 안내예요.
  • 「게시자: 알 수 없음」 은 프로그램에 회사 인증 서명이 아직 붙어 있지 않아서 나오는 표시예요.
  • 확인할 것은 하나예요. 원장톡에서 안내한 다운로드 링크로 받은 파일(wjtok-setup-판번호.exe)인지 봐 주세요. 다른 곳에서 받은 파일이라면 실행하지 마세요.

1내려받기

받는 브라우저에 따라 경고 모양이 달라요. 쓰시는 브라우저를 골라 주세요.

  1. 「일반적으로 다운로드되지 않습니다」 가 떠요

    오른쪽 위 다운로드 칸에 이렇게 나오면 받기가 잠깐 멈춘 상태예요. 위 안심 안내처럼 새 프로그램이라 뜨는 경고예요.

  2. 경고에 마우스를 올리고 … 를 누르세요

    마우스를 올려야 오른쪽에 휴지통과 … 단추가 보여요.

    휴지통을 누르면 받은 파일이 지워져요.

  3. 유지 를 누르세요

  4. 한 번 더 묻는 창에서 삭제 옆 ∨ 를 누르세요

    「열기 전에 … 신뢰할 수 있는지 확인합니다」 창이 떠요. 큰 삭제 단추가 아니라 오른쪽의 작은 화살표를 눌러야 해요.

    삭제 를 누르면 받은 파일이 지워져요. 그랬다면 처음부터 다시 받으면 돼요.

  5. 그래도 계속 을 누르세요

  6. 받기가 끝나면 파일 열기

    바로 설치 프로그램이 열려요. Edge 에서 이미 확인했기 때문에, 다음 단계의 윈도우 경고는 보통 다시 뜨지 않아요 — 그러면 3. 인증코드 넣기로 넘어가세요.

  1. 「의심스러운 다운로드 차단됨」 이 떠요 — 그 줄을 누르세요

    오른쪽 위에 이렇게 나오면 받기가 멈춘 상태예요. 새 프로그램이라 뜨는 경고예요.

  2. 의심스러운 파일 다운로드 를 누르세요

    「이 파일은 일반적으로 다운로드되지 않으며 위험할 수 있습니다」 는 처음 보는 파일이면 나오는 말이에요.

    기록에서 삭제 를 누르면 받은 파일이 지워져요.

  3. 받기가 끝나면 파일 옆 열기

    「최근 다운로드 기록」 에서 파일에 마우스를 올리면 오른쪽에 열기 단추가 보여요.

2실행하기

받은 파일을 열면 윈도우가 「Windows의 PC 보호」 창을 띄울 수 있어요. 크롬 · 웨일 등으로 받았다면 대개 이 창이 떠요.

  1. 추가 정보 를 누르세요

    처음에는 실행 안 함 단추만 보여요. 당황하지 말고 글 아래의 추가 정보 를 누르세요.

  2. 실행 을 누르세요

    「게시자: 알 수 없는 게시자」 는 회사 인증 서명이 아직 없어서 나오는 표시예요. 실행 을 누르면 설치 프로그램이 열려요.

3동의하고 인증코드 넣기

설치 프로그램이 차례로 묻는 것에 답하면 돼요. 관리자 비밀번호를 묻는 창은 뜨지 않아요.

  1. 이용약관 — 이용약관에 동의합니다 를 고르고 다음

    동의를 골라야 다음 이 눌려요.

  2. 개인정보 처리방침 — 아래 칸에 표시하고 다음

    글 아래 「개인정보 처리방침에 동의합니다」 칸에 표시해야 다음 이 눌려요.

  3. 인증코드 — 구매하신 인증코드를 넣고 다음

    ABCDE-FGHIJ-KLMNO-PQRST-UVWXY 모양의 코드예요. 복사해서 붙여 넣으면 틀릴 일이 없어요. 칸이 비어 있으면 다음 이 눌리지 않아요. 인증코드 하나로 PC 3대까지 쓸 수 있어요.

  4. 추가 작업 — 그대로 두고 다음

    「바탕화면에 아이콘 만들기」, 「윈도우 시작 시 자동 실행 (사용 권장)」 이 있어요. 예약 발송은 원장톡이 켜져 있어야 보내지므로 자동 실행을 켜 두기를 권해요. 나중에 설정에서 바꿀 수 있어요.

  5. 설치 준비 완료 — 설치

    고른 것을 한 번 더 보여 줘요. 설치 를 누르면 파일을 복사하고, 이어서 이 PC 를 인증해요. 잠깐 기다리세요.

  6. 끝 — 마침

    중간에 인증 오류 창 없이 이 화면이 나오면 설치와 인증이 다 끝난 거예요(오류 창이 떴다면 아래 「이럴 땐」 을 보세요). 「원장톡 실행」 에 표시된 채로 마침 을 누르면 바로 원장톡이 켜져요.

「설치 위치」 를 묻는 화면이 나오면 그대로 다음 을 누르세요.

이럴 땐 어떻게 하죠?

위험한 프로그램인가요?

아니요, 경고는 바이러스가 발견됐다는 뜻이 아니에요. 아직 많은 사람이 받지 않은 새 프로그램이면 브라우저와 윈도우가 한 번 더 확인하라고 띄우는 안내예요. 「게시자: 알 수 없음」 은 회사 인증 서명이 아직 없어서 나와요. 원장톡에서 안내한 다운로드 링크로 받은 파일인지만 확인해 주세요.

스마트스크린 경고로 설치를 할 수 없어요

추가 정보를 누른 뒤에도 실행이 보이지 않으면 두 경우예요. 회사 · 기관에서 관리하는 PC 라면 관리 담당자가 막아 둔 것이라 담당자에게 문의해 주세요. 윈도우 11 의 「스마트 앱 컨트롤」 이 켜져 있어도 실행 없이 막혀요. 이것을 끄는 것은 PC 보안 설정을 바꾸는 일이라, 직접 끄기 전에 구매처로 문의해 주세요.

경고가 하나도 안 떠요

정상이에요. 브라우저 설정이나 그동안 받은 사람 수에 따라 경고 없이 바로 받아지고 열리기도 해요. 그대로 설치하면 돼요.

웨일 등 다른 브라우저로 받았어요

크롬과 비슷하게 「위험할 수 있는 파일」 이라는 경고가 뜰 수 있고, 받은 파일을 열면 윈도우의 「Windows의 PC 보호」 창이 떠요. 위의 크롬 · 웨일 등 순서대로 하시면 돼요.

실수로 [삭제]를 눌렀어요

받은 파일만 지워진 거예요. 다운로드 링크에서 처음부터 다시 받으면 돼요.

「인증코드를 다시 확인해 주세요」 가 나와요

인증코드가 맞지 않는 거예요. 받은 인증코드를 복사해서 그대로 붙여 넣어 주세요. 앞뒤에 빈칸이 들어가지 않았는지도 봐 주세요.

「이미 PC 3대에서 쓰고 있습니다」 가 나와요

인증코드 하나로 PC 3대까지 쓸 수 있어요. 쓰지 않는 PC 의 원장톡에서 설정 → 인증해제로 자리를 비운 뒤 다시 설치해 주세요.

「인증 서버에 연결하지 못했습니다」 가 나와요

인터넷 연결을 확인하고 예를 눌러 다시 해 보세요. 아니요를 누르면 인증 없이 설치가 끝나고, 원장톡을 켜면 인증 화면이 떠요 — 재인증을 눌러 인증코드를 넣으면 돼요. 인증하기 전에는 보낼 수 없어요.

원장톡이 실행 중이라 설치할 수 없대요

창이 보이지 않아도 화면 오른쪽 아래 트레이에서 돌고 있을 수 있어요. 트레이의 원장톡 아이콘을 오른쪽 클릭 → 종료로 끝낸 뒤 확인을 눌러 주세요.

궁금한 것이 가이드에 없으면 구매처로 문의해 주세요.
